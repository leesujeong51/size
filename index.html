2 실무 반응형 5대 핵심 CSS 기법 & 코드 스니펫

CSS Media Queries

1. 모바일 퍼스트(Mobile-First) 미디어 쿼리

작은 화면 스타일을 기본으로 작성하고, 화면이 넓어질 때마다 min-width를 통해 레이아웃을 점진적으로 확장하는 가장 효율적인 방식입니다. 

/* 1. 기본 스타일: 모바일 (< 768px) */
.product-grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 12px;
}

/* 2. 태블릿 구간 (768px 이상) */
@media (min-width: 768px) {
  .product-grid {
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
  }
}

/* 3. PC 데스크톱 구간 (1024px 이상) */
@media (min-width: 1024px) {
  .product-grid {
    grid-template-columns: repeat(4, 1fr);
    gap: 24px;
  }
}
Responsive UX Pattern

2. 테이블(Table)을 모바일 카드 스택으로 변환

모바일에서 가로 스크롤로 잘려 보기 힘든 table을 td::before { content: attr(data-label) } 속성을 사용하여 세련된 카드로 전환합니다. 

/* 모바일: 표를 블록 카드형으로 재구성 */
@media (max-width: 767px) {
  .responsive-table thead { display: none; }
  .responsive-table tr { 
    display: block; 
    border-radius: 12px;
    margin-bottom: 12px;
    padding: 14px;
  }
  .responsive-table td {
    display: flex;
    justify-content: space-between;
    padding: 8px 0;
  }
  .responsive-table td::before {
    content: attr(data-label); /* HTML의 data-label 표시 */
    color: #888;
    font-weight: 600;
  }
}
Modern Web Standards

3. 모던 CSS 컨테이너 쿼리 (Container Queries)

전체 화면 너비가 아닌, 컴포넌트가 배치된 부모 영역의 너비를 측정하여 스타일을 바꿉니다. 사이드바나 다단 어디에 들어가도 깨지지 않습니다. 

/* 부모 요소를 컨테이너로 선언 */
.editorial-section {
  container-type: inline-size;
  container-name: article-card;
}

/* 컨테이너의 가용 폭이 700px 이상일 때 */
@container article-card (min-width: 700px) {
  .editorial-banner {
    flex-direction: row;
  }
  .editorial-title {
    font-size: 1.85rem;
  }
}
Fluid Sizing

4. 미디어 쿼리 없는 유동형 폰트 clamp()

수많은 미디어 쿼리 분기 없이도 화면 크기에 비례하여 폰트 크기가 부드럽게 늘어나고 최소/최대 한계치를 보장하는 기법입니다. 

/* clamp(최소 크기, 선호 비율, 최대 크기) */
.hero-title {
  /* 최소 1.85rem, 뷰포트 폭에 따라 부드럽게 증가, 최대 3.25rem */
  font-size: clamp(1.85rem, 5vw + 0.5rem, 3.25rem);
  line-height: 1.25;
}

.hero-desc {
  font-size: clamp(0.95rem, 1.2vw + 0.4rem, 1.15rem);
}
