# 📱💻🖥️ 반응형 뷰포트 스튜디오 (Responsive Viewport Studio)

> **원하는 웹사이트 URL을 입력하여 모바일, 태블릿, PC 기기별 화면이 어떻게 구성되고 변화하는지 실시간으로 비교·검증할 수 있는 반응형 웹 테스터 & 스튜디오**

---

## 🌟 주요 기능 및 화면 모드

### 🌐 1. 실시간 URL 및 로컬 파일 입력 지원 (New!)
- **로컬 프로젝트 파일 완벽 지원**:
  - `file:///C:/Users/.../index.html` 또는 `C:\Users\...` 등 아직 깃허브나 웹에 배포하기 전인 내 컴퓨터의 HTML 파일 경로를 그대로 주소창에 넣으면 즉시 로드됩니다.
  - 내장된 **로컬 파일시스템 브리지(`/localfs/...`)**가 작동하여, 브라우저의 `file://` 보안 차단 없이 해당 폴더 내의 상대경로 CSS, JS, SVG 아이콘, 이미지까지 100% 정상 로드됩니다.
  - **`[⭐ 내 로컬 앱 (모어해빗)]`** 원클릭 프리셋 버튼 제공!
- **어떤 URL이든 자유롭게 입력**: 상단 전용 주소창에 `https://...`, `localhost:3000`, `localhost:5173` 등 테스트하고 싶은 웹페이지 주소를 입력하고 [이동] 또는 `Enter`를 누르면 모바일, 태블릿, PC 및 시뮬레이터 화면이 해당 사이트로 일괄 전환됩니다.
- **빠른 테스트 프리셋**:
  - `🎓 기본 데모 (한국방송통신대학교)` : 고등교육 국립 종합대학 반응형 공식 웹사이트
  - `⭐ 내 로컬 앱 (모어해빗)` : 사용자가 작성한 로컬 루틴 앱 즉시 로드
  - `🟢 네이버 (Naver)` : 모바일 m.naver.com / PC www.naver.com 자동 분기
  - `📚 위키백과` : 반응형 웹 대표 사례
  - `⚡ Tailwind CSS` : 반응형 프레임워크 쇼케이스
  - `💻 localhost:3000` : React, Next.js 로컬 개발 서버
  - `💻 localhost:5173` : Vite, Vue, Svelte 로컬 개발 서버
- **⚡ 보안 우회 프록시 (X-Frame-Options Bypass)**:
  - 외부 대형 사이트 중 타 사이트의 iframe 임베드를 차단하는 `X-Frame-Options: SAMEORIGIN` 또는 CSP 보안 정책이 적용된 사이트도, 내장된 `server.py`의 스마트 리버스 프록시를 통해 헤더를 우회하여 iframe 내부에 정상 렌더링되도록 지원합니다.
- **🔗 새 탭 열기 연동**: 현재 입력된 URL을 브라우저 새 창에서 바로 열어볼 수 있는 원클릭 버튼 제공.

### 📱 2. 3분할 기기 동시 비교 뷰 (Side-by-Side Comparison)
- **📱 모바일 (Mobile)**: `390 × 844 px` (iPhone 15 Pro 스타일 실물 프레임, 다이나믹 아일랜드, 홈 바)
- **💻 태블릿 (Tablet)**: `768 × 1024 px` (iPad Air 스타일 프레임, 사파리 툴바)
- **🖥️ PC 데스크톱 (Desktop)**: `1200 × 800 px` (MacBook Pro 스타일 창 크롬, 탭, URL 바)
- **⚡ 스크롤 연동 기능 (Sync Scroll)**: 하나의 기기에서 스크롤하면 다른 기기도 동일한 비율로 동시 스크롤되어 각 섹션의 변화를 1:1로 직접 비교 가능!
- **🔍 줌 배율 제어 & Fit**: 50%, 65% (권장), 75%, 90%, 100% 및 화면 맞춤 Fit 원클릭 스테퍼
- **⛶ 포커스 모드 (Focus)**: 단일 기기를 화면 전체로 확대 검수 및 `Esc`로 3분할 복귀
- **📝 접이식 QA 패널**: 기기별 정상/확인필요/문제 판정 및 메모 자동 저장

### 🎛️ 3. 자유 리사이즈 시뮬레이터 (Device Simulator & Resizer)
- **실시간 드래그 리사이징**: 마우스로 우측 및 하단 핸들을 잡고 드래그하면 320px ~ 1600px까지 부드럽게 반응형 레이아웃이 변환되는 과정을 실시간 확인.
- **상단 브레이크포인트 눈금자 (Ruler)**: 모바일(`<768px`), 태블릿(`768~1023px`), PC(`1024px+`) 영역 구분 및 현재 폭 인디케이터 제공.
- **다양한 기기 프리셋**: iPhone SE, iPhone 15 Pro, Galaxy S24, iPad Mini, iPad Air, Small PC, MacBook 13", Wide Desktop 원클릭 전환.
- **화면 회전(Rotate)**: 가로(Landscape) 및 세로(Portrait) 즉시 회전 테스트.

### 📚 4. 반응형 디자인 스펙 & 가이드 (RWD Guide & Checklist)
- **기기별 UX/UI 비교 매트릭스**: 해상도, 내비게이션, 컬럼 수, 터치 vs 마우스, 테이블 표시법, 타이포그래피.
- **실무 5대 핵심 CSS 기법 코드**: 모바일 퍼스트 미디어 쿼리, 테이블→카드 변환 기법, 모던 컨테이너 쿼리(`@container`), 유동형 폰트 `clamp()`.
- **퍼블리싱 체크리스트**: 뷰포트 메타태그, 가로스크롤 방지, 터치 타깃 48px 규칙 등.

## 🚀 실행 방법

### 방법 A. 원클릭 실행 (가장 추천! 프록시 기능 포함)
`responsive-device-showcase` 폴더 안의 **`start_server.bat`** 파일을 더블 클릭하면 자동으로 프록시 지원 로컬 웹 서버(`server.py`)가 실행되고 기본 브라우저에서 `http://localhost:8080`이 열립니다.

### 방법 B. Python 명령어로 직접 실행
```bash
cd C:\Users\이수정\.gemini\antigravity\scratch\responsive-device-showcase
python server.py 8080
```
브라우저에서 `http://localhost:8080` 접속

### 방법 C. 브라우저에서 직접 파일 열기
- `index.html` 파일을 크롬, 엣지, 웨일 등 브라우저로 드래그 앤 드롭하여 바로 열어볼 수 있습니다.
- (참고: 외부 보안 차단 사이트의 프록시 우회 기능은 로컬 웹 서버 환경인 `start_server.bat` 실행 시 작동합니다)
